## 1. 目标与范围

输入论文/补充材料，或经授权的目标研究仓库；输出具有原文/代码/运行证据定位的偏倚风险报告、可执行检查脚本和修复建议。自动完成能做的步骤，不能验证的事项明确保留，不将缺证据猜成无风险。

首个应用领域为临床预测研究，方法工具沿用研究锁定的PROBAST/PROBAST+AI版本。未取得完整官方题目及使用条件前，只提供明确标识的工程风险检查，不声称完成正式工具评价。不要把本文规划当已实现功能。

### 两种模式

- 文献模式：获取合法文本、分段定位、提取研究设计、检索相关证据和补充材料、提出逐项风险判断并交叉复核。只能评价报告证据，不能认证实际代码或患者数据。
- 项目模式：读取授权协议、代码和元数据；在目标研究仓库生成/适配检查脚本，测试后执行，获得聚合证据。数据不出本地；LLM不接收患者行、逐行预测或凭据。检查成立的前提是导出完整且与真实执行对应。

## 2. agent工作链

输入范围与权限 → 研究类型/工具版本识别 → 文档与代码证据索引 → 风险任务分解 → LLM分析/脚本适配 → 确定性检查 → 独立上下文或不同模型复核 → 报告/待决项。

证据不足时自动扩大合法材料检索范围或查找补充资料，受调用次数、时间和费用预算约束。仍不足则结束为未验证，不无限循环，也不为了得到肯定答案重复调用。

模型和角色分工：

| 角色 | 工作 | 限制 |
|---|---|---|
| 编排器 | 管理阶段、权限、预算和任务依赖 | 由代码控制，模型不能自授权限 |
| 提取/检索模型 | 结构化研究信息、候选证据排序 | 轻量模型可选，缺少时沿用已验证模型并如实记录 |
| 分析模型 | 方法语义、证据关系、风险解释 | 原文锚定，不将常识补成事实 |
| 编码agent | 生成和修复研究检查脚本 | 脚本写入目标研究仓库，先测试再受控执行 |
| 独立复核agent | 核对出处、反证、脚本与报告一致性 | 同模型不同上下文不是独立模型或专家金标准 |
| 确定性工具 | 哈希、交集、时间约束、拟合成员和运行对账 | 不以LLM评分替代 |

不要求所有角色采用不同模型；先跑通工作流，再按实测能力/成本选择模型。Jev可作后续结构化判断后端，不依赖Jev或微调才能交付。

## 3. 自动输出与权限

每项发现包含：工具/问题或工程规则ID、结论类别、原文定位/引用或代码与运行定位、依据、反证、覆盖范围、缺失材料、机器检查状态、模型/规则来源、建议动作。

分开报告：
- 确定性检查确认的违例（仅对已检查清单/运行范围成立）；
- LLM根据文档或代码推断的风险；
- 证据不足/不可验证；
- 已检查范围内未检出违例（不等于整体低风险）。

可自动生成逐题/领域评价草案，标识自动生成、所用版本和证据范围。不以未校准confidence自动作正式科学接受。用户无须逐篇标注；只有来源授权、科学协议变更、破坏性动作、无法解释的关键语义才提出有限的决策问题。授权范围内的正常检查无需反复确认。

生成代码视作不可信执行产物：静态检查与合成测试之后，由受限运行器执行；限制目录、网络、超时、输出和写入范围。不提供任意shell自动执行，也不把当前Hermes禁工具包装当OS沙箱。第一阶段默认只读检查，修复写入与重新训练分别受授权约束。

## 4. 没有人工标注时如何验收

采用多层证据，不伪造专家准确率：

1. 软件与故障注入：在合成元数据/最小代码例中植入患者重叠、未来特征、全量拟合、旧审计和遗漏运行。由构造规则提供可计算预期，测试发现与拒绝能力。
2. 来源及引用检查：DOI/题名/版本、文本哈希、逐字引文、补充材料定位与结论追踪自动核验；命中引用不等于语义正确。
3. 可获得的公开既有专家评价：许可允许且模型/结果/问题版本可匹配时，作为外部参照，不要求用户新标注。论文级领域判断不机械拆成片段金标签；来源冲突和无法映射单列。
4. 独立LLM复核与反事实探针：检查解释、反证和已知语义变化。AI一致只作一致性证据，不称准确率或真值。
5. 端到端公开案例：记录从输入到报告的成功、失败、阻塞、证据覆盖、调用预算与实际耗时。无有效参照时不报告偏倚判断precision/recall或“媲美专家”。

只有带可靠预期的故障集合或适配的既有参考集才能计算相应检测指标；始终限定总体。没有人工金标准不妨碍构建与发布自动化辅助工具，但限制对其真实科学判断准确性的声称。

## 7. 微调与教学支线

在agent可用后或不阻塞主线时，可用许可明确的公开标注、规则合成样本、强模型生成的silver标签学习微调/蒸馏/校准。标清标签来源与噪声；自动生成标签不能同时充当自己的独立效果证明。小模型优先用于检索、路由和结构化提取，替换某部件前对比质量、成本和失败。

训练仍放配套实验环境/仓库，不加入标准库skill核心。Colab延后至微调阶段；不要求现在登录，也不启动训练。教学随工程推进，默认用户有深度学习基础，以任务分解、检索增强、工具调用、程序验证、代理复核和故障分析为主，微调知识按支线实际实验讲解。
