# 研究契约（DRAFT）

空项必须填实，或写明不适用的科学理由。已有活动协议时引用它并补齐定位；这份模板不能覆盖既有批准。

## Protocol

- study_id / protocol_id / version：
- 目标研究仓库与当前代码状态：
- 研究问题、假设、目的（预测/因果/描述/其他）：
- 估计目标或预测目标；个体、事件、会话及分析单位：
- 确证性与探索性边界；可支持和不可支持的结论：
- 目标人群、就诊场景、使用时点及预期适用范围：
- 数据来源、发布/清单身份、使用授权及允许访问范围：
- 入组与排除、可核验字段和时点；无法核验的条件：
- 时间锚点、预测时点、历史窗、结局窗；时间戳单位/时区：
- 结局定义、采集/判定、盲法、删失、竞争事件及随访：
- 允许和禁止的预测信息；实际可用时间规则：
- 评价工具、版本、部分、官方文件来源/哈希和适用题目：
- 数据切分单位、时期/中心边界、各分区用途、最终测试权限：
- 样本量/事件规模或估计精度依据，复杂度及设计效应：
- 主指标、接受条件、方向；次指标及不确定性方法：
- 基线、对照、预算、种子、停止条件和失败处理：
- 数据处置与预处理拟合边界；缺失、未知、异常值语义：
- 调参、筛选、重采样、阈值和校准的拟合/选择权限：
- 内部、时间及外部验证与预先指定的敏感性分析：
- 独占写入者、资源预算、环境身份、运行登记、输出路径：
- 批准者与批准证据、批准绑定的版本、协议锁身份：
- 偏离与修订规则、只读复核要求、最终接受标准：

## 审批与冻结

本文件起始状态为 DRAFT。签署、批准和冻结必须对应填好的确切版本。空模板、文件检查 PASS 和软件合成检查都不是实验授权。

批准后保持协议文件不变；审计和结果写到其他文件并引用其 SHA-256。新发现先作为缺证据/偏离记录，不能悄悄改协议。
