# Medical Research Harness

把研究问题和偏倚风险转换成数据操作、可执行实验任务及可复核结果。按用户当前阶段推进；复用目标项目已有管线、协议和运行登记。首个完整方法学路径是临床预测研究。

版本：0.1.0-alpha。Python 3.10+，核心脚本仅依赖标准库。plan/audit/summarize/check_bundle 可独立运行；preflight 需通过 `--lab` 指定受信任的外部校验器，接口见 [operations.md](references/operations.md)。本包不包含 ResearchLab 运行器。源码采用附带的 [MIT License](LICENSE)。

## 先确定研究与证据

1. 读取目标项目规则、研究目标、数据契约、活动协议、最新决定、代码和已有结果。区分计划、已执行证据和未解决问题。
2. 分类研究目的：个体预测、因果/干预、描述或其他。预测研究读取 [methodology.md](references/methodology.md) 并锁定工具版本；其他类型先指定适用协议和评估工具，不能套用 PROBAST 评分。
3. 读取 [workflow.md](references/workflow.md) 中当前阶段。没有契约时用 [protocol.md](assets/protocol.md) 创建草案；存在协议则引用并补齐定位，不另造相冲突的版本。

## 将指导落实为操作

用户要求推进时，读取 [operations.md](references/operations.md)，在目标项目完成对应产物，不能只交付标准对比或建议清单。

1. 根据研究目标和现有协议写入具体 `study.json`；生成含实际命令的任务规格。缺少科学决策时列明待决项，不猜测终点、时间或切分。
2. 在授权范围内适配目标项目的数据导出器，生成私有 rows/folds/planned-fits 清单，运行 `study.py audit --mode planned`，按违例修复实现。
3. 用 `study.py preflight` 核对审计身份并调用现有 runner 的审批/锁校验；通过后只执行已授权任务。每次实际 fit 留下输入成员记录，运行 `audit --mode executed`。
4. 用 `study.py summarize` 对账全部尝试，再完成官方逐题判断与科学复核。计划清单不能充当执行证据；输出必须明确成功、失败、未结束和未执行任务。

上述脚本支持明确的数据契约；不兼容的研究按 operations.md 所列边界记录需要的适配，不能改研究设计来迎合检查器。

## 三个操作

- **设计**：输出研究契约、偏倚控制表、数据处理任务和实验矩阵。任务必须包含输入、允许操作、禁止操作、命令、接受标准、输出和偏离处理。
- **数据与执行前检查**：追踪标识、入组、时点、标签、切分和拟合边界；输出聚合 QC 和缺失证据。执行研究实验之前要求已有科学批准、协议锁、任务规格、运行登记和唯一写入者。已授权协议的正常执行不重复请求批准。
- **评估与汇总**：结合实现和实际运行产物完成逐题判断，单列适用性；汇总全部尝试、失败和敏感性结果。新的只读复核后，写清已支持、未支持和受限制的结论。

每项偏倚风险都要形成 `风险 → 具体操作 → 检查/实验 → 证据定位 → 剩余风险`。例如：预处理泄漏对应“训练折拟合”，由拟合行归属审计验证；时间泄漏对应“预测时点前可用”，由可用时间违例计数验证。

## 证据检查

从 [evidence_bundle.json](assets/evidence_bundle.json) 生成目标项目的证据清单。所有路径相对清单所在目录；可以用不同 locator 把多种角色定位到同一份文档。执行：

```bash
python3 <skill-directory>/scripts/check_bundle.py <study-directory>/evidence_bundle.json
```

`phase` 为 `design`、`preflight` 或 `results`。填好的文件以 `available` 加 SHA-256 和 locator 登记；尚未完成的标 `planned`/`missing`。必要角色缺失时检查失败；不适用需有理由文档，核心协议、审批和结果角色不能豁免。详见工作流的角色表。

check_bundle.py 通过仅表示文件证据的一致性；实际清单检查与运行对账使用 study.py。两者都不自动赋予低风险或科学有效性。不要把文档完整性视为无泄漏。

## 持续遵守的边界

- 固定人群、结局、时间锚点、特征时点、切分、主指标、停止条件和结论边界；改变这些需协议修订和批准。
- 不把患者行、逐行预测、嵌入或凭据写进技能、共享记忆或提示。保留数据版本/清单哈希与聚合证据。
- 先确定切分，再在训练折拟合填补、缩放、编码、筛选、重采样和调参。测试集不参与模型、阈值、校准或报告策略选择。
- 未报告表示缺少判断证据；确认的实现缺陷才是缺陷。不适用必须说明。缺证据不能默认低风险。
- 不把检查器成功、合成测试、较高 AUC 或显著性当作研究成功、临床效用或治疗效果。
